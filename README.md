# 🚀 Overview

KhanayWala AI Frontend is a modern React application that provides an intuitive user experience for food discovery, restaurant browsing, online ordering, and AI-powered meal recommendations.

The frontend communicates with the FastAPI backend using REST APIs and is designed with scalability, responsiveness, and clean UI architecture in mind.

# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/abizaid24/khanaywala-ai-frontend.git

cd khanaywala-ai-frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment

Create `.env`

```env
VITE_API_URL=http://localhost:8000
```

---

## Run Development Server

```bash
npm run dev
```

Application

```
http://localhost:5173
```
